# eg2-rag 시스템 아키텍처 가이드

## 1. 개요 및 배경
`eg2-rag`는 로컬 온디바이스 인공지능 기반의 고속 시맨틱 검색 시스템입니다.
Intel Core Ultra 7 프로세서의 AI Boost NPU 하드웨어 가속을 활용하여 상시 백그라운드 색인을 수행합니다.

## 2. 파일 무훼손 원칙 (Zero-Modification Guarantee)
- 인덱싱 작업 중 사용자의 원본 파일은 읽기 전용 공유 모드(`FILE_SHARE_READ | WRITE | DELETE`)로 열립니다.
- 인덱싱 대상 폴더 내부에는 어떠한 임시 파일(`.tmp`, `.lock`)도 생성하지 않습니다.
- 원본 파일의 수정 시각(`mtime`) 및 접근 시각(`atime`)은 완전히 보존됩니다.

## 3. 자원 조절기 (Resource Governor)
시스템의 CPU 사용량이 65%를 초과하거나 RAM 사용량이 80%를 초과하면 인덱서가 작업을 자동으로 일시 중단(Yield)하여 사용자 작업 환경의 쾌적성을 보장합니다.

## 4. 지식 묶음 (Knowledge Bundle)
사용자는 파이썬 코드(`*.py`, `*.ipynb`), C++ 소스코드(`*.cpp`, `*.hpp`), 마크다운 문서(`*.md`) 등 관심 대상만을 묶어서 선별적으로 시맨틱 검색을 수행할 수 있습니다.
